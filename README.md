# Career Compass AI

Create a premium, modern, AI-powered web application called “HireLens”.

The platform is an intelligent career acceleration platform designed for students, freshers, and professionals who want to improve their resumes, prepare for interviews, analyze skill gaps, and receive AI-powered career guidance through an advanced chatbot assistant.

The website should look like a billion-dollar SaaS startup product, not a college project. The design quality should be comparable to products like Notion, Stripe, Linear, Framer, and modern IBM enterprise dashboards.
